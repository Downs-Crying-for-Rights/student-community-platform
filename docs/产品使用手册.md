# 学互会产品使用手册

> 适用站点：[forum.dcr2026.com](https://forum.dcr2026.com)
> 文档版本：1.0
> 更新日期：2026 年 7 月 18 日
> 适用对象：平台用户、倾听者、DCR Helper、审核员、管理员和超级管理员

## 1. 产品概述

学互会是面向学生群体的分层交流与互助平台，主要包含以下产品区域：

| 区域 | 用途 | 访问条件 |
| --- | --- | --- |
| 公共社区 | 浏览、发布、评论和发现普通帖子 | 已登录用户 |
| 消息中心 | 通知、私信和群聊 | 已登录用户 |
| 知识库 | 查询政策、合规渠道、权益须知和平台指南 | 按文章可见范围开放 |
| DCR 互助区 | 委托审核、互助任务、工单、证据和互助循环 | 入口公开，核心功能需完成 DCR 准入 |
| 心理交流区 | 受控成员社区和匿名树洞 | 需提交申请并审核通过 |
| 管理后台 | 用户、内容、准入、DCR、日志和系统管理 | 按管理角色授权 |

平台采用响应式布局：PC 端使用左侧导航，手机端使用底部导航和“更多”菜单。页面上可见的入口会根据用户角色和准入状态自动调整。

## 2. 角色与权限

| 角色 | 主要权限 |
| --- | --- |
| 普通用户（USER） | 使用公共社区、消息、群聊、知识库，并申请 DCR 或心理区准入 |
| 可信用户（TRUSTED_USER） | 在普通用户权限基础上使用平台授予的可信功能 |
| DCR Helper | 参与并处理 DCR 互助任务、工单和证据流程 |
| 审核员（MODERATOR） | 进入审核看板，执行被授权的内容审核工作 |
| 管理员（ADMIN） | 管理用户、内容、准入、委托、群聊、任务、争议等业务 |
| 超级管理员（SUPER_ADMIN） | 拥有全部管理能力，并可使用遥测、系统维护、站点内容等高权限功能 |

实际可见菜单和可执行操作以当前账号权限为准。没有权限的页面会跳转至登录页或 403 页面。

# 用户部分

## 3. 注册、登录与新手引导

### 3.1 注册账号

1. 打开站点，进入“注册学生交流社区”。
2. 按页面要求填写用户名、邮箱、密码、手机号和短信验证码；如使用邀请码，再填写邀请码。
3. 阅读并同意相关协议后提交。
4. 根据页面提示完成邮箱验证、手机号绑定或后续新手引导。

注意事项：

- 用户名、邮箱或手机号不能与已有账号重复。
- 密码长度为 8—72 个字符，建议使用大小写字母、数字和符号组合。
- 短信验证码有有效期，过期后请重新获取；不要连续快速请求验证码。
- 邀请码是否必填、可用次数和有效期由管理员配置。

### 3.2 登录账号

登录页可能提供以下一种或多种方式：

- 邮箱与密码登录；
- 邮箱魔法链接登录；
- 手机号与验证码登录。

使用魔法链接时，应在同一浏览器中打开最新邮件中的链接。若页面提示链接过期或登录失败，请重新申请一封邮件，不要继续使用旧链接。

### 3.3 完成新手引导

首次进入平台时，根据页面完成平台新手题目和基础设置。提交成功后即可进入社区。管理员可以在“平台新手指引题库”中维护这些题目。

## 4. 页面导航

### 4.1 PC 端

左侧导航通常包含：

- 首页：查看信息流；
- 发现：查看热门话题、热门板块和推荐内容；
- 消息：查看通知、私信和群聊；
- 群聊：直接进入群聊列表；
- 发布：创建帖子；
- 心理区：通过准入后显示或开放；
- DCR 互助：进入 DCR 准入页或工作台；
- 我的：进入个人主页；
- 管理：有管理权限时显示。

### 4.2 手机端

底部固定显示首页、发现、发布和消息等核心入口。个人主页、群聊、DCR 互助、心理区和审核入口位于“更多”菜单中。进入子页面后，可以使用返回按钮或底部导航切换主要功能。

## 5. 首页、发现、搜索与知识库

### 5.1 首页

首页用于浏览帖子信息流。点击帖子标题或卡片进入详情，可查看正文、附件、作者信息和评论。

### 5.2 发现

“发现”页提供：

- 热门话题；
- 热门板块；
- 每周推荐内容。

点击对应卡片即可进入帖子、话题或板块。

### 5.3 搜索

使用搜索功能查找帖子、用户或其他已开放内容。搜索结果只会展示当前账号有权限访问的信息；心理区等受限内容不会泄露给未获准用户。

### 5.4 知识库

知识库支持按“政策学习、合规渠道、权益须知、平台指南”等分类筛选，也可按标题或正文关键词搜索。点击文章卡片查看全文。

## 6. 发布与互动

### 6.1 发布帖子

1. 点击导航中的“发布”。
2. 选择目标板块或专区。
3. 填写标题和正文；正文支持 Markdown。
4. 按需添加标签、图片或附件。
5. 如果发布 DCR 互助内容，可选择关联本人参与且已审核通过的委托或工单。
6. 提交发布。

发布到心理区时，系统会自动按心理区规则隐藏作者身份；只有已获准成员可以查看。请勿在标题、正文、图片或附件中主动填写真实姓名、学校、住址、电话等可识别个人的信息。

### 6.2 帖子互动

在帖子详情页可以：

- 点赞或取消点赞；
- 收藏或取消收藏；
- 发表评论和回复；
- 点击用户头像进入对方主页；
- 对违规内容发起举报；
- 编辑或删除自己有权管理的内容。

可执行的操作会受到帖子状态、板块权限和账号角色限制。

### 6.3 个人主页与设置

进入“我的”可查看个人主页和相关内容。进入“个人设置”可以修改：

- 头像；
- 昵称；
- 个人简介；
- 登录密码；
- 页面主题。

公开资料中不要填写敏感个人信息。

## 7. 消息、私信与群聊

### 7.1 消息中心

消息页集中提供：

- 全部通知；
- 互动通知；
- 系统通知；
- 群聊；
- 私信会话。

可以逐条标记已读，也可以使用全部已读功能。与审核、准入、委托、任务和争议有关的结果会通过系统通知发送；在邮件配置可用时，重要结果也会发送至账号邮箱。

### 7.2 一对一私信

可从用户主页或已经建立的互助关系发起私信。进入会话后即可发送和查看消息。

使用建议：

- 不要在私信中发送身份证号、家庭住址、账号密码等敏感信息；
- 不要绕过平台进行收费、转账或危险线下接触；
- 遇到骚扰、威胁或欺诈时，保留证据并举报。

为处理投诉和保障平台安全，获得授权的管理员可以在后台审查私信内容；后台审查行为不会在用户会话中显示为参与者。

### 7.3 群聊

消息页的“群聊”标签展示可发现的公开群聊和本人已经加入或创建的群聊。

创建公开群聊的流程：

1. 点击创建群聊；
2. 填写群聊名称和介绍；
3. 提交后等待管理员审核；
4. 审核通过后，群聊对符合条件的用户可见；
5. 审核被拒绝时，根据拒绝原因修改后重新提交。

群主或群管理员可以处理入群申请和成员管理。被禁言或移出后，相应功能会受到限制。

## 8. DCR 互助区

### 8.1 四步准入

从“DCR 互助”进入 DCR 工作台。首次使用时按顺序完成：

1. 验证手机号；
2. 完成 DCR 入频考核；
3. 填写并提交统一互助委托表；
4. 等待管理员审核。

委托表审核通过后，关联的 DCR 准入申请会自动通过并授予访问权限。已审核通过的委托表可以在后续发布委托时直接复用，无需每次重新审核。

### 8.2 填写统一互助委托表

委托表通常包括：

- 内容类型；
- 学校名称、类型和地址；
- 已尝试的举报途径；
- 详细情况；
- 收费情况；
- 具体诉求；
- 年级、时间、地区等可选信息；
- 风险偏好（必填，需明确选择不限、仅站内沟通、可电话或仅模板咨询）；
- 信息真实性和隐私确认。

一次委托原则上只描述一所学校。提交前使用敏感内容预览检查个人信息，确认无误后提交。提交成功页会明确显示“管理员正在审核”。

### 8.3 查看委托审核状态

在 DCR 工作台进入“我的求助”或“查看委托与审核状态”。常见状态如下：

| 状态 | 含义 | 用户操作 |
| --- | --- | --- |
| 待审核 | 已提交，等待管理员处理 | 等待通知 |
| 人工审核中 | 系统建议进一步确认 | 等待管理员处理 |
| 需补充信息 | 材料不完整或需要解释 | 按备注补充材料并提交 |
| 已通过 | 委托可用于后续发布和互助 | 进入工作台继续操作 |
| 已驳回 | 当前材料不符合要求 | 查看理由，修正后重新提交 |

委托未通过前不会向所有用户公开。审核结果会通过站内通知发送，在邮件服务可用时也会发送邮件。

### 8.4 互助任务

“互助任务”页面可以按推荐、最新和紧急程度浏览任务。一个用户可以接取多个委托，一个委托也可以由多人提供帮助。

参与方式：

1. 打开任务详情；
2. 查看对方委托、任务说明和风险提示；
3. 点击接取或提出互助；
4. 如果自己有委托，系统会同时向对方展示双方委托；
5. 双方都同意后进入正式互助流程；
6. 在任务会话中沟通，并按要求提交图片、录音或其他证据；
7. 双方确认完成，或按流程发起争议。

没有自己委托的用户也可以作为“大好人”直接帮助他人，不会因为缺少委托而被阻止。实际可接取范围仍受账号状态、风险规则和任务状态限制。

常见任务状态：草稿、已提交、审核中、开放接取、已接取、互助中、待证据、已完成、已驳回、已关闭和争议中。

### 8.5 工单、沟通与证据

“我的工单”可按全部、待处理、处理中、待补充和已关闭筛选。

- 待处理：工单已创建，等待 Helper 接入；
- 处理中：Helper 已接入并处理；
- 待补充：需要提交者补充信息；
- 已关闭：处理流程结束。

在允许的状态下，可以在工单或任务会话中发送文字、图片、录音等内容。证据应与当前事项直接相关，并避免包含无关人员的敏感信息。需要导出证据或进入争议处理时，按页面确认提示操作。

### 8.6 双方与三方互助循环

互助循环支持两种模式：

- 双方互助：A 帮助 B，同时 B 帮助 A；
- 三方系统匹配：系统根据用户提交的需求和可提供帮助，形成 A → B → C → A 的闭环；人数不足时可由可用管理员补位。

双方模式下选择另一位参与者，并可填写各方向的互助说明。三方模式只需提交“希望获得的帮助”和“可以提供的帮助”，无需手动指定 B、C。匹配和接受互助后，参与者会自动获得 Helper 工作台权限。

循环状态包括组建中、互助中、已完成和已中断。

## 9. 心理交流区

### 9.1 申请准入

进入“心理区”后，点击“申请加入心理区”，阅读准入说明和倾听者守则，完成申请并等待审核。页面会显示申请状态；审核通过后入口变为“进入心理区”。

### 9.2 匿名树洞

审核通过的成员可以进入“心理区匿名树洞”浏览和发布内容。平台会隐藏心理区帖子及评论的作者身份，但用户仍需主动避免在正文和附件中暴露个人信息。

心理区是同伴支持空间，不是医疗机构或紧急服务。遇到即时危险、自伤或伤人风险时，应立即联系可信成人，并拨打 110、120 或页面列出的心理援助热线。

### 9.3 倾诉匹配

当前“倾诉匹配”功能暂时关闭。请使用心理区匿名树洞或页面提供的专业求助资源，不要等待平台匹配处理紧急情况。

## 10. 举报、申诉与常见错误

### 10.1 举报内容

在帖子、评论、用户或任务相关页面使用举报入口，选择原因并补充必要说明。管理员会在审核看板或争议队列中处理。

### 10.2 常见提示

| 提示 | 处理方式 |
| --- | --- |
| 参数校验失败 | 检查必填项、字符长度、分页数量或数据格式 |
| 无权访问 / 403 | 确认登录状态、角色和专区准入是否满足 |
| 登录链接已过期 | 重新申请最新魔法链接 |
| 验证码错误或已过期 | 重新获取验证码，并使用最新一条 |
| 内容需要审核 | 等待管理员处理，不要重复快速提交 |
| 需要补充信息 | 查看审核备注，在原流程中补充材料 |
| 服务暂时不可用 | 稍后重试，并向管理员提供发生时间、页面和操作步骤 |

# 管理员部分

## 11. 进入管理后台

拥有审核或管理权限的账号可从 PC 左侧导航或手机端“更多”中的“管理”进入后台。后台菜单会按角色显示：

- 审核员主要使用审核看板；
- 管理员处理用户、内容、准入、委托、群聊、任务和争议；
- 超级管理员额外管理遥测、系统维护、DCR 教程和站点内容。

涉及授权、删除、封禁、证据导出和系统重启的操作应先核对目标对象，必要时填写原因。关键操作会进入审计日志。

## 12. 审核看板与内容管理

### 12.1 审核看板

用于处理进入审核队列的帖子、评论或其他内容。审核时应：

1. 阅读完整上下文；
2. 核对举报原因和敏感内容命中；
3. 选择通过或驳回；
4. 填写清晰、可复核的处理说明。

### 12.2 内容管理

“内容管理”分别提供帖子和评论列表，可按关键词、状态等条件筛选，并执行平台允许的管理操作。管理员可将已发布帖子置顶或取消置顶；置顶不会绕过板块、可见性和 DCR 准入规则。删除或调整置顶前应填写原因，并尽量保留必要的审计或争议证据。

### 12.3 板块管理

可以创建板块，填写名称和描述，并编辑、启用、禁用或删除现有板块。调整板块前应检查是否仍有关联帖子以及该板块的访问规则。

### 12.4 知识库管理

可以新增、编辑、发布、下线或删除知识库文章。文章分类应使用统一名称，标题应明确，政策类文章应标注适用范围和更新时间。

## 13. 用户、邀请码与准入管理

### 13.1 用户管理

“用户管理”支持筛选用户，并按权限执行角色调整、封禁/解封和资料覆盖等操作。

操作原则：

- 只授予完成工作所需的最低角色；
- 调整管理员或 Helper 角色前核对账号身份；
- 封禁和覆盖资料时填写原因；
- 不要通过后台查看或传播与处理事项无关的个人信息。

### 13.2 邀请码

“邀请码管理”可以生成邀请码、查看使用状态并按条件筛选。生成时设置合理的数量、有效期和用途；泄露或滥用的邀请码应及时停用。

### 13.3 准入审核

“准入审核”用于处理心理区和 DCR 等访问申请。打开申请后查看守则确认、关联材料和历史状态，选择通过或驳回，并填写审核备注。

DCR 准入应与委托表关联，不应批准缺少有效关联委托的申请。心理区准入应重点确认申请者是否理解隐私、同伴支持边界和危机处理原则。

## 14. DCR 管理

### 14.1 委托表审核

从“委托表审核”进入审核队列。审核时检查：

- 是否只涉及一所学校；
- 学校名称、地区、年级、时间等字段是否明确；
- 描述与诉求是否完整；
- 是否包含个人可识别信息、诱导或其他风险内容；
- 自动抽取字段、缺失字段和敏感命中是否合理；
- 系统建议仅作为参考，最终结果由管理员确认。

可选结果包括：

- 通过：委托进入可用状态，并自动批准关联的 DCR 准入；
- 需补充：注明具体缺少什么，便于用户一次补齐；
- 人工审核：保留在队列中继续核查；
- 驳回：填写明确、可操作的驳回理由。

审核通过后用户可复用该委托发布后续互助任务，无需重复审核同一份委托。

### 14.2 DCR 入频考核题库

可以新增、编辑、启用、禁用和删除 DCR 入频题目。每道题应有明确题干、选项和正确答案。修改已上线题目前，应确认不会导致现有准入规则前后矛盾。

### 14.3 任务管理

“全部互助任务”展示各状态任务。管理员可审核任务、通过、驳回、关闭或进入详情处理，并按流程导出证据。

审核重点：

- 任务必须关联有效委托时，检查关联关系；
- 任务说明应与委托一致；
- 多人接取时分别检查各互助会话状态；
- 对证据、图片和录音执行最小必要查看；
- 驳回、关闭或导出证据必须填写原因并确认操作。

### 14.4 互助循环管理

后台提供三类能力：

- 指定互助对象：管理员直接选择参与者并形成互助关系；
- 推荐方案：根据等待用户的需求和可提供帮助生成候选组合；
- 自动分配：由系统为等待中的三方匹配申请建立闭环。

执行分配前应检查利益冲突、地域风险、需求与能力匹配。系统自动分配后仍应关注是否有人拒绝、超时或导致循环中断。

### 14.5 争议处理

“争议仲裁队列”用于查看互助任务、时间线、证据和争议说明。处理流程：

1. 打开关联任务并阅读完整时间线；
2. 核对双方委托、会话和证据；
3. 避免只依据单方描述作出结论；
4. 选择处理结果并填写必填原因；
5. 确认相关用户收到站内通知和邮件结果。

## 15. 群聊与私信治理

### 15.1 群聊审核

按待审核、已通过和已拒绝等状态筛选群聊。待审核群聊应检查名称、介绍、创建人和预期用途。通过后公开群聊才进入可发现范围；拒绝时填写具体原因。

对于已经运行的群聊，可以根据平台规则处理入群申请、成员权限和禁言。禁言应记录原因、执行人、有效期及解除信息。

### 15.2 私信审查

“私信审查”展示会话列表和选中会话的内容，仅用于投诉调查、安全处置和合规审核。

管理要求：

- 不得出于好奇浏览用户私信；
- 只查看与当前投诉或风险事件有关的会话；
- 不向无关人员复制或传播内容；
- 必要操作应通过审计日志可追溯；
- 管理员不会作为成员出现在用户私信会话中。

## 16. 题库、教程与站点内容

### 16.1 平台新手指引题库

可新增、编辑、启用、禁用或删除新手题目。更新后应使用普通测试账号走一次完整新手流程，确认题目、选项和答案正常显示。

### 16.2 DCR 教程

超级管理员可以维护 DCR 教程章节，编辑标题与正文，并调整章节顺序。发布前检查链接、政策时效和用户操作路径。

### 16.3 站点内容

超级管理员可以创建、编辑、预览和删除 Markdown 站点文档，例如用户协议、隐私政策和帮助说明。内容键应稳定，避免随意更名导致已有链接失效。

### 16.4 公告管理

超级管理员可发布 Markdown 公告，并按需启用强制弹窗和私信群发。强制弹窗只能由用户点击“我已阅读并确认”关闭；公告正文更新后版本递增，用户需要重新确认。

私信群发仅投递给已同意私信巡查授权且未封禁的用户，并使用只读“平台公告”账号发送，同时生成系统通知。群发按批次执行并保存每位用户的唯一投递记录，重复处理不会向同一用户重复发送。发布和群发前应核对标题、正文、受众和敏感信息，避免频繁打扰用户。

## 17. 审计、日志与遥测

### 17.1 操作日志

“操作日志”记录管理操作，可按操作者、动作、对象和时间筛选，并导出 CSV。调查异常操作时，应先记录筛选条件和时间范围，再导出留档。

### 17.2 服务器控制台

“系统日志”以终端样式展示服务器输出，支持：

- 暂停或继续自动刷新；
- 立即刷新；
- 清空当前页面显示；
- 复制日志；
- 按日志级别、来源和关键词筛选；
- 翻页查看历史输出。

“清空当前显示”只清理浏览器中的显示内容，不等同于删除服务器日志。处理故障时记录发生时间、发布版本、请求 ID、用户 ID和错误堆栈。

### 17.3 应用遥测

超级管理员可以在“应用遥测”查看：

- 前端错误和页面异常；
- 服务端接口错误；
- 请求状态码与耗时；
- Web Vitals；
- 热门路由；
- 用户、会话、发布版本和请求 ID；
- 错误消息、字段校验详情和完整上下文。

排查步骤：

1. 按错误级别、事件类型、路由、状态码或关键词筛选；
2. 打开事件详情，确认发生时间和发布版本；
3. 根据请求 ID 对照服务器控制台；
4. 复现用户操作并记录输入条件；
5. 修复部署后，确认新版本中同类事件不再增长。

遥测会对常见敏感凭据自动脱敏，但管理员仍不得复制、公开或长期保存不必要的用户数据。

## 18. 系统维护

“系统维护”仅供超级管理员使用。强制刷新重启用于清理应用缓存并重启服务，使新版本资源和页面状态保持一致。

建议流程：

1. 确认没有正在执行的数据迁移或重要导出；
2. 记录当前发布版本；
3. 在低峰时段执行强制刷新重启；
4. 等待页面提示完成；
5. 验证首页、登录、消息、DCR、心理区和管理后台；
6. 在遥测和服务器控制台确认没有持续新增错误。

强制重启不能替代正式部署，也不会自动修复数据库结构、环境变量或第三方服务配置错误。

## 19. 管理员日常检查清单

### 每日

- 查看待审核内容、准入、委托表和群聊；
- 查看 DCR 任务、待补充事项和争议；
- 检查遥测新增错误和服务器控制台异常；
- 关注邮件、短信、OSS 等外部服务失败。

### 每周

- 复核用户封禁、角色授权和邀请码使用；
- 检查知识库和站点政策内容是否需要更新；
- 查看互助循环中断、任务超时和重复争议；
- 导出必要的审计记录并按制度保存。

### 每次部署后

- 确认自动部署成功；
- 核对线上 `/DEPLOYMENT` 与目标提交；
- 使用普通用户和管理员账号分别执行关键路径冒烟测试；
- 检查新接口是否已纳入遥测；
- 确认旧静态资源和缓存没有造成页面版本不一致。

## 20. 支持信息采集模板

用户报告问题时，请尽量收集：

- 账号 ID 或用户名（不要索取密码）；
- 发生时间；
- 页面地址；
- 操作步骤；
- 页面提示或错误信息；
- 事件 ID、请求 ID；
- 浏览器和设备类型；
- 必要的截图；
- 是否可以稳定复现。

不要通过聊天或工单索取用户密码、邮箱授权码、短信验证码、访问密钥或其他秘密凭据。
